This note is inspired from the condensed matter physics courses instructed by *prof. Vaezi*. Here, instead of telling some wierd "rules" of quantizing fields (although historically this is exactly the way we've quantized the classical mechanics of particles), I started with some many-body quantum-mechanical problems. This motivated the formulation of second quantization (I tried to be as accurate and direct as possible, so the method can resolve any misunderstanding about second quantization) and I've shown how it makes the life easier. It ended up with intruducing creation/annihilation operators and actually the non-relativistic QFT. After introducing some methods in the simplified QFT (non-relativistic), I've tried to move toward the relativistic theory. This is actually a QFT note with a condensed-matter taste. *(WORK IN PROGRESS)*
